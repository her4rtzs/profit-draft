# AGENTS.md describes both portal surfaces instead of one
- Decision: Split the old single "Web (staff portal)" stack line into one line for static `web/` and one for Django `templates/` + `components/` + `static/`; add `web/` to the repo layout, update `ROADMAP.md`, and leave the shared Rules section unchanged.
- Reason: Testing each named technology against each folder showed the old line was wrong for `web/` but right for `templates/`, which cannot be retired because `accounts/accept_invite.html` serves the emailed staff invite; deleting the line would have left the Rules demanding tools with no owner.
- Trade-offs: The Rules section still reads as if the portal were one surface; the owner was told rather than having it edited.
- Evidence: `AGENTS.md`, `web/`, `templates/`, `accounts/accept_invite.html`, `ROADMAP.md`; Source: PROJECT-LOG.md, 2026-10-18 17:40.
